# customer-churn-analysis
Customer Churn Analysis using Python, Pandas, SQL, Matplotlib and Seaborn to identify churn patterns, customer behavior and revenue at risk.


# 1. Project Title
Customer Churn Analysis – Python

## 2. Short Description
A customer churn analysis project developed using Python, Pandas, SQL, Matplotlib, and Seaborn. The project analyzes customer churn patterns, subscription details, customer behavior, complaints, escalations, and revenue at risk.

## 3. Tech Stack
Python – Main programming language used for data analysis

Pandas – Used for data cleaning, transformation, and analysis

NumPy – Used for numerical operations and feature engineering

SQL / SQLite – Used for working with and analyzing structured customer data

Matplotlib – Used for creating data visualizations

Seaborn – Used for statistical visualizations and correlation analysis

Jupyter Notebook – Used for analysis and documentation

## 4. Data Source

Customer Churn Dataset

The dataset contains customer and subscription information including customer ID, subscription dates, plan type, contract type, cancellation details, monthly charges, CLTV, churn score, complaints, escalations, CSAT score, and tenure.

## 5. Business Problem

The business needs to understand customer churn and identify factors that may be associated with customer cancellations.

The main objective is to analyze churn patterns, compare customer and subscription characteristics, identify trends over time, and estimate revenue at risk due to customer churn.

## 6. Analysis & Highlights
-Overall Customer Churn Analysis
-Churn Analysis by Plan Type
-Monthly Churn Trend Analysis
-Revenue at Risk Analysis
-ARPU (Average Revenue Per User) Analysis
-Customer Tenure Analysis
-Complaint and Escalation Analysis
-Churn Risk Analysis
